True Myth Web Components Example

InstanceProvider

Provides component instances through Dependency Injection container. 

<instance-provider component-type="result"
                value="initial-value"></instance-provider>

Result Component

Represents a computation that can succeed (Ok) or fail (Error).

<true-myth-result value="success" is-ok></true-myth-result>

Error Component

Represents a failed computation.

<true-myth-error value="error message"></true-myth-error>

Task Component

Represents an asynchronous computation.

<true-myth-task value="initial"></true-myth-task>

Maybe Component

Represents an optional value (Just or Nothing).

<true-myth-maybe value="optional" is-just></true-myth-maybe>

Check Console

Open your browser's developer console to see the component interactions and test results.
